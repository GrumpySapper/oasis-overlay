# Christmas gift-thanks clips (preview only)

Used by `overlay-xmas-preview.html` and the standalone demo `gift-thanks-xmas-preview.html`. The live overlay (`overlay.html` + `sounds/thanks/`) is unchanged.

Each `thanks-*.mp3` is a sleigh-bell / “Jingle Bells” motif followed by a spoken Santa-style thank-you. `msg-*.mp3` are the voice lines on their own (for the demo). Clips rotate so the same file is not played twice in a row. Bigger tiers use a slightly lower, slower voice and a longer jingle.

See `SOURCES.md` for licence. Peaks are about −3 dBFS. The overlay still honours `?vol=` and `?sound=0`, and keeps the existing burst throttle (gap between clips, cap of six waiting, one thank-you per gifter on a combo).
